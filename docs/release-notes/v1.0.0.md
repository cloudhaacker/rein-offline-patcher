First public release.

A Windows tool that patches the NieR Re[in]carnation APK and content tables for a lunar-tear private server on your own PC, without Google Colab. After the first run it works offline.

## Download

Get **rein-offline-patcher-v1.0.0.zip** below, unzip it to a short path such as `C:\NierPatcher`, and double-click `Start Patcher.bat`. The [README](https://github.com/cloudhaacker/rein-offline-patcher#readme) has the full steps.

You need your own copies of the game's 3.7.1 APK and `20240404193219.bin.e`. No game files are included.

## What it does

- Patches the APK with your server address, then rebuilds, aligns and signs it
- Patches the content tables file
- Checks a patched APK, and can compare it with another to show what differs
- Downloads everything it needs into its own folder on first run (about 85 MB)

## Please know before using

- All patching is done by the lunar-tear authors' own scripts (lunar-scripts), downloaded from their GitLab and run unchanged. Credit for the patches is theirs.
- The code and documentation here were written by an AI (Claude, by Anthropic), directed and tested by the repository owner. No human has reviewed the code line by line.
- Testing so far: one Windows PC and MuMu Player. The content tables output is byte-for-byte identical to the Colab notebook's. Real phones and other setups are untested.
- Known open issue: one LDPlayer setup showed a black screen with an APK that ran in MuMu Player.

Reports of what works and what does not are welcome in Issues.
